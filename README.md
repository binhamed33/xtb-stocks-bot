# بوت أبحاث الأسهم الحلال على Discord (XTB)

**المالك والحقوق: Abdulrhman AL-Riyami** © 2026 — جميع الحقوق محفوظة.

منصة أبحاث استثمارية مدعومة بالذكاء الاصطناعي (Google Gemini فقط) للمستثمر طويل الأجل الذي يشتري **أسهماً حقيقية** عبر XTB ويلتزم بالأسهم **المتوافقة مع الشريعة**.

- لا CFD إطلاقاً. البوابة الثانية لكل توصية هي التحقق من أن الأداة سهم حقيقي متاح في XTB، وما لم يُتحقق منه يُصنّف UNVERIFIED ولا يُعرض كفرصة قابلة للاستثمار.
- لا تصنيف HALAL بلا بيانات ومنهجية ومصدر وتاريخ فحص.
- لا بيانات أو أسعار أو أخبار أو روابط مختلقة: كل رقم يحمل مصدره ووقت تحديثه وهل هو متأخر أم تقديري.
- لا تنفيذ تلقائي لأي صفقة.

## الأوامر (Slash commands)

| الأمر | الوظيفة |
|---|---|
| `/analyze SYMBOL` | تحليل كامل: البوابات (شرعي + XTB)، الخلاصة، الفني، الأساسي، الأخبار، المخاطر |
| `/report SYMBOL` | تقرير استثماري من 18 قسماً مع المصادر والمراجع |
| `/stock SYMBOL` | السعر والمعلومات الأساسية |
| `/sharia SYMBOL [method] [rescreen]` | الفحص الشرعي: المنهجية (AAOIFI/MSCI/FTSE)، النسب، الأسباب، المصادر، التاريخ، ما لم يُتحقق منه، سجل الفحوص |
| `/news SYMBOL` | الأخبار مع تاريخ النشر والمصدر والرابط وأثرها المحتمل + إفصاحات SEC الرسمية |
| `/scan [min_drop] [limit]` | مسح القائمة بحثاً عن أسهم هبطت ولديها أساسيات سليمة وتعافٍ محتمل |
| `/opportunities` | نتائج آخر مسح |
| `/market` | المؤشرات وحالة الجلسة والافتتاح القادم بتوقيتك |
| `/compare A B` | مقارنة شركتين |
| `/portfolio show/add/remove` | محفظتك: القيمة، الربح/الخسارة، التوزيع، المخاطرة، التوافق الشرعي لكل مركز |
| `/watchlist show/add/remove` | قائمة المتابعة (مراقبة تلقائية) |
| `/alerts show/add/remove` | تنبيهات: هبوط %، سعر مستهدف، كسر سعر، خبر جوهري، تغير شرعي، نتائج، انعكاس اتجاه |
| `/xtb status/verify/cfd/unavailable/import` | سجل التحقق من الأسهم الحقيقية في XTB |
| `/ask QUESTION [SYMBOL]` | سؤال حر يجيب عنه Gemini من البيانات الحقيقية فقط |
| `/help` | شرح البوت وطريقة الاستخدام مع أزرار للأقسام |
| `/status` | حالة المصادر وGemini والاستهلاك (للمشرفين) |

إضافة إلى المنشورات المجدولة القديمة عبر الـ Webhook (تنبيه الصباح، نشرة ما قبل الافتتاح، الفتح، منتصف الجلسة، الإغلاق، أيام العطل).

## نظام الفحص الشرعي

ثلاث منهجيات موثقة لا تُخلط:

| | AAOIFI (المعيار 21) | MSCI Islamic | FTSE Shariah |
|---|---|---|---|
| الأساس | القيمة السوقية | إجمالي الأصول | إجمالي الأصول |
| الدين الربوي | < 30% | < 33.33% | < 33.33% |
| النقد والأوراق الربوية | < 30% | < 33.33% | < 33.33% |
| الذمم + النقد | — | < 33.33% | < 50% |
| الدخل غير الجائز | < 5% | < 5% | < 5% |

فحص النشاط يستبعد البنوك والتأمين والتمويل الربوي، الكحول، التبغ، القمار، الخنزير، المحتوى الإباحي، الترفيه والإعلام التقليدي، الأسلحة، القنب، منصات العملات الرقمية؛ والصناعات المختلطة (مطاعم، فنادق، ألعاب فيديو...) تُعلَّم QUESTIONABLE.

التصنيفات: **HALAL** / **NON_COMPLIANT** / **QUESTIONABLE** / **UNVERIFIED**. يُعاد الفحص تلقائياً كل `SHARIA_RESCREEN_DAYS` يوماً ويُحفظ السجل.

قيود صادقة: نسبة الدخل غير الجائز تُقدَّر من بند دخل الفوائد في قائمة الدخل عند توفره؛ وإن لم يتوفر يُنزَّل الحكم إلى QUESTIONABLE ويُذكر ذلك. للتأكد النهائي استخدم فاحصاً معتمداً (Zoya, Musaffa) وأضف ما تتأكد منه في `HALAL_WHITELIST`.

## التحقق من السهم الحقيقي في XTB

XTB أوقفت واجهتها البرمجية في مارس 2025 ولا تنشر قائمة أدوات قابلة للقراءة آلياً، لذلك لا يوجد تكامل مباشر، والبوت لا يدّعي وجوده. آلية التحقق:

1. `/xtb verify SYMBOL` بعد أن تتأكد في xStation أن الأداة **سهم** (وليس CFD) بحسابك.
2. `/xtb import` لملف CSV بالصيغة `symbol,type[,market,currency,min_qty]`.
3. اختيارياً `XTB_TRUST_HEURISTIC=true` لقبول "سهم مدرج في بورصة تخدمها XTB بالأسهم الحقيقية" مع وسم النتيجة صراحة كتخمين.

## مصادر البيانات

| المصدر | الاستخدام | التكلفة |
|---|---|---|
| Yahoo Finance (yfinance) | الأسعار، القوائم المالية، الأخبار | مجاني، متأخر ~15 دقيقة، غير رسمي |
| SEC EDGAR | إفصاحات 8-K/10-K/10-Q/Form 4 | مجاني، رسمي، يتطلب User-Agent |
| Finnhub | أخبار ومقاييس إضافية | مفتاح مجاني اختياري |
| Financial Modeling Prep | ملف الشركة والنسب | مفتاح مجاني اختياري (محدود يومياً) |
| Google Gemini | تلخيص الأخبار، السرد، المقارنة، الأسئلة | مفتاح من AI Studio |

طبقة `providers/` تسمح بإضافة مزود أو استبداله دون تغيير التحليل. التخزين المؤقت في SQLite (أسعار 5 دقائق، تاريخ ساعة، أساسيات 12 ساعة، أخبار 30 دقيقة) مع تسجيل استهلاك كل API.

## الموقع (tdawl.riyami.om)

واجهة ويب على نفس المحرك ونفس قاعدة البيانات: بحث عن أي سهم، بطاقة الحكم الشرعي وXTB، التقييم من 100 مع حلقة متحركة، رسم السعر مع EMA 20/50/200، كل أقسام التقرير، الأخبار بروابطها، الفرص، السوق مع عدّاد الافتتاح، المحفظة مع توزيع قطاعي، المتابعة، التنبيهات، سؤال Gemini، والمساعدة.

- الدخول بحساب Discord نفسه (OAuth2) فيرى العضو محفظته وتنبيهاته التي أنشأها في الشات. أو رمز دخول مشترك (`WEB_ACCESS_CODE`)، أو وضع مفتوح للأبحاث فقط.
- الأوامر الإدارية (مسح، تأكيد XTB، الحالة) للمشرفين في `ADMIN_USER_IDS`.
- حد للطلبات لكل مستخدم في الدقيقة، كوكي موقّع HttpOnly، المفاتيح لا تصل للمتصفح.

```bash
# بعد install.sh وبعد توجيه سجل A للدومين إلى السيرفر:
sudo DOMAIN=tdawl.riyami.om EMAIL=you@example.com bash /opt/xtb-stocks-bot/deploy/install-web.sh
```

يثبّت Nginx وخدمة `xtb-stocks-web` وشهادة Let's Encrypt (certonly: لا يلمس أي موقع آخر على السيرفر). تسجيل الدخول بـ Discord يحتاج `DISCORD_CLIENT_ID` و`DISCORD_CLIENT_SECRET` من Developer Portal مع إضافة Redirect `https://tdawl.riyami.om/auth/callback`.

## التثبيت على السيرفر

```bash
curl -fsSL https://raw.githubusercontent.com/binhamed33/xtb-stocks-bot/main/deploy/install.sh | sudo bash
sudo nano /opt/xtb-stocks-bot/.env
sudo systemctl restart xtb-stocks-bot
sudo journalctl -u xtb-stocks-bot -f
```

المفاتيح: `DISCORD_BOT_TOKEN` للأوامر التفاعلية (Discord Developer Portal)، `GEMINI_API_KEY` للذكاء الاصطناعي (Google AI Studio)، والبقية اختيارية. بدون توكن البوت تعمل المنشورات المجدولة فقط؛ بدون Gemini يعمل كل شيء بتحليل برمجي.

التحديث: `sudo bash /opt/xtb-stocks-bot/deploy/update.sh`
